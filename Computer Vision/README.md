Computer Vision: Root Segmentation and Analysis
This project uses computer vision techniques to segment and analyze plant roots from images. The main objective is to extract root structures and calculate key features like total length.

Features
⚙️ U-Net-based root segmentation

🧠 Trained and evaluated models (Model 1, Model 2, Final Model)

🧪 Inference pipeline for new images

📏 Root length calculation using skeletonization

Files
Final_Model.ipynb – Final training and evaluation notebook

Final_Pipeline.ipynb – Complete pipeline for segmentation and analysis

Inference_Notebook.ipynb – Use pretrained model to predict on new images

Root Segmentation.ipynb – Segmentation model development

Root Length Calculation.ipynb – Measurement of root length

task5_test_image_prediction_victoria_233182_RETAKE2.png – Example predicted output image

How to Use
Clone the repository and open the notebooks.

Run Final_Pipeline.ipynb for full processing.

Use Inference_Notebook.ipynb for testing on new images.

Dependencies
Python (3.8+)

OpenCV, NumPy, Scikit-image

TensorFlow or PyTorch (depending on model)
