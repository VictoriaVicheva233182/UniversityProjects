# Predicting Incident Severities with Machine Learning  
*Victoria Vicheva – Breda University of Applied Sciences*

## Overview

This project aims to build a machine learning model that can accurately predict the **severity of incidents** based on historical data. The model supports risk management teams in responding to incidents more proactively and efficiently.


## Objective

To classify incidents into different **severity levels** based on features such as incident type, time, location, and other contextual factors.

## Key Components

- 📊 Data preprocessing and feature engineering  
- 🧠 Supervised ML models (e.g., decision trees, gradient boosting)  
- 📈 Evaluation using metrics like accuracy, precision, recall, and F1-score  
- 🔍 Use of confusion matrices and feature importance for explainability  

## Business Value

- 🚨 Early identification of high-risk incidents  
- 📉 Helps reduce response time and resource misallocation  
- 📊 Enhances strategic planning and incident mitigation

## Tools & Technologies

- 🐍 Python (pandas, scikit-learn, matplotlib)  
- 📁 Jupyter Notebook for iterative development  
- 🧪 Model testing and evaluation on labeled datasets

## Deliverable

A machine learning pipeline capable of classifying incident severity with actionable insights for decision-makers.

> 📌 *This project applies AI to real-world safety and operations contexts, demonstrating how data science supports risk-based planning.*
