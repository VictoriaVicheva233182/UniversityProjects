What is DKS-AI Chatbot?

✓ Deployment Ready

Complete Docker containerization achieved: All components (Ollama model, FastAPI backend, React frontend) are containerized and tested on company PC. System includes email-based security - only users with @kokstaal.nl email addresses can create accounts and access the system.

🔄 How It Works (RAG Pipeline)

  1. User asks question in chatbot
  2. System searches relevant document chunks in FAISS database
  3. Top results are sent to Mistral 7B as context
  4. AI generates answer based on real documents
  5. Answer with source citations is displayed

Challenges & Learnings

What Did I Learn?

⚠️ Major Challenges

  • Database Corruption: Lost significant processing work - implemented backup strategy
  • Hardware Constraints: Development on laptop (16GB) - not enough for production scale
  • Excel Processing: Numerical extraction complex - continuous optimization
  • System Stability: Balancing new features vs stability - chose stability

✓ Key Learnings

  • RAG > Fine-tuning: For business constraints (hardware/time), RAG was better choice
  • Empirical Evaluation: Tested 3 models - Mistral 7B won on performance
  • Production Thinking: Prototype ≠ Production - learned enterprise requirements
  • Stakeholder Validation: Early testing with end-users = critical for success

🎯 Strategic Decisions

Why RAG?

• No fine-tuning hardware needed
• Faster development (20-week constraint)
• Easy to update with new docs
• Transparent source attribution

Why Mistral 7B?

• Best performance of 3 tested models
• Good multilingual support (NL/EN)
• Runs locally on consumer hardware
• Open-source & updatable
