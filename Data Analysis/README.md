# Data Analysis: NAC Breda Player Evaluation  
*Victoria Vicheva – Breda University of Applied Sciences*

## Overview

This project investigates the potential of young football players at NAC Breda using advanced data analysis and machine learning. The work was conducted under a Non-Disclosure Agreement (NDA), and only the final report is shareable.

## Objective

To answer the question:  
**Are young players undervalued, or do they need further training and investment to enhance their performance?**

## Key Components

- 📊 Exploratory Data Analysis (EDA) of 16,000+ records
- 🤖 Machine Learning model (Gradient Boosted Trees) for performance evaluation
- 📈 Analysis of trends in player age, market value, and game metrics
- ✅ Ethical handling of sensitive data in compliance with GDPR

## Deliverable

The final report includes data-driven recommendations for strategic player development at NAC Breda.

> 📌 *Due to the NDA, source code and datasets cannot be shared.*
