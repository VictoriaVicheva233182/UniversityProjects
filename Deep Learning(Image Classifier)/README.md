# Skin Cancer Identification using Deep Learning  
*Victoria Vicheva – Breda University of Applied Sciences*

## Overview

This project focuses on building a **deep learning image classification model** to support faster and more accurate identification of skin cancer, specifically melanoma. The model aims to improve early diagnosis and treatment outcomes in clinical settings.

## Objective

To classify images of skin lesions into three categories:
- Skin with **benign moles** (non-cancerous)  
- Skin with **suspicious lesions**  
- Skin **positive for melanoma**

## Key Components

- 📂 Dataset: 600 medical images (200 per class)
- 🧠 Model: Transfer Learning using **MobileNet**, trained on augmented data
- 📈 Final test accuracy: **75%**
- 🔍 Comparison with human-level performance (30–40%)

## Development Process

- ✅ Data preprocessing, resizing, and one-hot encoding  
- 🧪 Multiple training iterations: from basic MLP to Xception and MobileNet  
- 🔄 Data augmentation and transfer learning  
- 🔬 Responsible AI practices: XAI techniques (e.g. Grad-CAM, Guided Backpropagation)  

## Human-Centered Design

- 👥 Think-aloud user testing and A/B testing conducted  
- 🗣 Feedback informed interface usability and model explainability

## Business Value

- ⚕️ Faster and more accurate diagnosis of skin cancer
- 💰 Reduced need for unnecessary tests and treatments
- 📉 Lower misdiagnosis rates, improved patient outcomes

> 📌 *This project demonstrates applied skills in AI for medical diagnostics, with an emphasis on ethical AI and fairness.*
