# SDG Dashboard Analysis (Power BI)  
*Victoria Vicheva – Breda University of Applied Sciences*

## Overview

This project explores and visualizes key **Sustainable Development Goal (SDG)** indicators using interactive dashboards created in Power BI. The aim is to uncover patterns, highlight progress, and inform decision-making on global development goals.

## Objective

To provide a clear, data-driven overview of SDG progress through interactive visual storytelling.

## Key Components

- 📊 Power BI dashboards presenting SDG indicators
- 🌍 Insights into global trends related to health, education, and sustainability
- 📈 Interactive filtering by region, year, and indicator category
- 🔍 In-depth analysis of key performance metrics

## Deliverables

- `2331_VictoriaVicheva_Dashboard1_SDG_Indicators.pbix`: Main SDG indicators dashboard  
- `233182_VictoriaVicheva_Dashboard_Analysis.pbix`: Deeper analysis and insights dashboard
