# IRIS: Plant Phenotyping Website  
*Victoria Vicheva – Breda University of Applied Sciences*

## Overview

**IRIS** is a user-friendly web application designed to support plant scientists in analyzing root structures through computer vision and AI. Built for the **Netherlands Plant Eco-phenotyping Centre (NPEC)**, IRIS enables automated plant root segmentation, measurement, and visualization — all from a modern browser interface.

> 🚧 **Note:** This project is still in development. Some features and sections are in progress.

## Objective

To provide an end-to-end, browser-based platform for:
- 🌱 Uploading plant root images
- 🔍 Performing automated segmentation and analysis
- 📈 Displaying visual and numeric results
- 📥 Downloading reports and data for further use

## Key Features

- 🧠 **AI-Powered Analysis:** Segmentation and measurement using a FastAPI backend  
- 🖼️ **Interactive Frontend:** HTML-based interface with clear progress steps  
- 📊 **Quantitative Insights:** Root length, branching, and phenotyping metrics  
- 📂 **Downloadable Results:** Export images and tables for research documentation  
- 🧬 **Human-Centered Design:** Clean, accessible interface and helpful documentation

## Application Structure

- `index.html` – Home and upload page  
- `analysis.html` – Image analysis step  
- `results.html` – Visualization of computed results  
- `download.html` – Export analyzed data  
- `main.py` – FastAPI backend with 3 key analysis endpoints  
- `about.html`, `contact.html`, `documentation.html` – Support pages

## Technology Stack

- ⚙️ **Frontend:** HTML/CSS, responsive layout, animated UI  
- 🧪 **Backend:** FastAPI (Python), modular API for analysis  
- 🖥️ **Deployment-ready:** Designed for local or cloud container deployment
