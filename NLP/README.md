# Emotion Classification using NLP  
*Victoria Vicheva – Breda University of Applied Sciences*

## Client

This project was developed in collaboration with the **Content Intelligence Agency**, a company that builds AI-powered software for analyzing video content, such as films, series, and TV shows. The goal is to integrate emotion recognition into their media analysis pipeline.

## Project Overview

The focus of this NLP project is **emotion classification** — the task of detecting and categorizing emotions expressed in text. This work contributes to improving automatic understanding of emotional tone in transcribed media dialogue.

## Objective

To build a natural language processing pipeline capable of classifying one of six **core emotions** from text:

- **happiness**
- **sadness**
- **anger**
- **surprise**
- **fear**
- **disgust**

## Key Components

- 🧠 Emotion classification using **Large Language Models (LLMs)**  
- 📄 Cleaned and labeled datasets based on Ekman’s six core emotions  
- 🔁 Preprocessing pipeline to normalize emotional labels and handle nuanced language  
- 🧪 Model evaluation using metrics like precision, recall, and F1-score

## Development Highlights

- ⚙️ Data cleaning with attention to synonyms and emotional connotation  
- 🔍 Label mapping based on Ekman's emotion taxonomy  
- 🗃 Integration-ready design for deployment in media content pipelines  
- 🧬 Consideration of linguistic complexities: sarcasm, polysemy, idioms, and slang

## Business Value

- 🎬 Enhances automated media analysis for video producers and editors  
- 🤖 Improves tagging of emotional tone in scripts and subtitles  
- 📊 Enables deeper viewer sentiment insights for creative and strategic decisions

> 📌 *This project demonstrates practical application of NLP in media tech, with a focus on emotion-aware AI systems.*
